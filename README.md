# Fortal Weather ☀️ ⛈️

This is my personal project, built to collect weather data from Fortaleza. The
project is _split into two parts_ (front-end and back-end), and this is the
_Front-end portion_.

To install dependencies:

```bash
bun install
```

To start a development server:

```bash
bun dev
```

```bash
bun start
```
